# Muscat Magazine 웹사이트

에디터의 귀로 고른 음악을 소개하는 인디 음악 매거진 **머스캣 매거진**의 웹사이트입니다.
피그마 디자인(데스크톱 1440 / 모바일 375)을 그대로 구현했습니다.

- **사이트**: Next.js (반응형, 데스크톱·모바일)
- **관리자 화면**: Payload CMS — 사이트 주소 뒤 `/admin`
- **데이터베이스**: Postgres (Vercel에서 Neon 연결)
- **이미지 저장소**: Vercel Blob
- **배포**: Vercel

## 페이지 구성

| 주소 | 내용 |
| --- | --- |
| `/` | 홈 — 대표 글, 최신 글, 다루는 분야, 인스타그램 팔로우 |
| `/articles` | 아티클 목록 — 종류(리뷰·큐레이션·인터뷰·발매)·장르 필터, 정렬 |
| `/articles/[주소]` | 아티클 상세 — 글 종류에 따라 4가지 화면 (앨범 리뷰 / 인터뷰 문답 / 플레이리스트 트랙 목록 / 발매 목록) |
| `/artists/[주소]` | 아티스트 페이지 — 사진, 에디터 소개글, 기본 정보, 듣기 링크, 인터뷰, 관련 아티클 |
| `/genres/[주소]` | 장르 페이지 — 그 장르의 아티스트와 아티클 |
| `/search` | 검색 — 아티스트·글 제목·태그 검색, 장르로 찾기 |
| `/about` | 소개 — 문구는 관리자 화면의 "About 페이지"에서 수정 |
| `/contact` | 문의 폼 — 들어온 문의는 관리자 화면 "문의"에 쌓임 |

## 관리자 화면에서 하는 일 (`/admin`)

- **아티클**: 제목, 글 종류, 커버, 관련 아티스트·장르를 정하고 "본문" 탭에서 종류별 내용을 입력합니다.
  - 앨범 리뷰 → "다룬 앨범"에 앨범마다 리뷰와 듣기 링크
  - 인터뷰 → "질문과 답"에 배경 설명·질문·답·인용구
  - 플레이리스트 → "트랙 목록"
  - 발매 소식 → "발매 목록"
  - 임시저장(Draft)으로 두면 사이트에 안 보이고, **Publish**를 눌러야 공개됩니다.
  - "홈 대표 글로 걸기"를 체크하면 홈 상단에 크게 걸립니다.
- **아티스트**: 사진, 장르, 한 줄 소개와 소개글, 활동 지역·시기, 듣기·SNS 링크. 아티클에서 아티스트를 연결하면 아티스트 페이지에 자동으로 쌓입니다.
- **장르**: 이름과 정렬 순서. 검색 화면의 "장르로 찾기"에 순서대로 보입니다.
- **사이트 설정**: 홈 문구, 이메일, 인스타그램·유튜브·블로그 주소, 풋터 문구, (Shop 오픈 시) 사업자 정보.
- **About 페이지**: 소개 문장, Approach, 하는 일, 원칙.
- **문의 / 뉴스레터 구독자**: 사이트에서 들어온 문의와 구독 이메일.

## 처음 배포하기 (Vercel)

1. https://vercel.com 에 GitHub 계정으로 로그인 → **Add New → Project** → 이 저장소 선택 → Import
2. 배포 전에 **Storage** 탭에서 두 가지를 만들어 프로젝트에 연결합니다.
   - **Neon (Postgres)** → 연결하면 `DATABASE_URL` 등이 자동으로 들어갑니다.
   - **Blob** → 연결하면 `BLOB_READ_WRITE_TOKEN`이 자동으로 들어갑니다.
3. **Settings → Environment Variables**에 직접 두 개를 추가합니다.
   - `PAYLOAD_SECRET` : 아무 긴 무작위 문자열 (예: 비밀번호 생성기로 만든 40자 이상)
   - `NEXT_PUBLIC_SERVER_URL` : 사이트 주소 (예: `https://muscat-magazine.vercel.app`, 도메인 연결 후엔 그 주소)
4. **Deploy**. 빌드할 때 데이터베이스 표가 자동으로 만들어집니다.
5. 배포된 주소 뒤에 `/admin`을 붙여 들어가면 **첫 관리자 계정**을 만드는 화면이 나옵니다.
6. 관리자 화면에서 장르 → 아티스트 → 아티클 순서로 내용을 넣습니다.

도메인은 Vercel 프로젝트의 **Settings → Domains**에서 연결합니다.

## 내 컴퓨터에서 실행하기 (개발용)

Node.js 22 이상과 Postgres가 필요합니다.

```bash
cp .env.example .env        # 값 채우기
npm install
npm run dev                 # http://localhost:3000, 관리자 http://localhost:3000/admin
npm run seed                # (선택) 화면 확인용 샘플 데이터
```

데이터 구조(컬렉션 필드)를 바꾼 뒤에는 배포 전에 마이그레이션을 만들어 함께 올립니다.

```bash
npm run payload migrate:create 변경내용이름
```

## 나중에 붙일 것

- **Shop (CD 판매)**: 같은 관리자 화면에 상품 컬렉션을 추가하고, 결제(PG) 연동과 장바구니·주문 화면을 붙입니다. 피그마의 Shop 화면 디자인을 그대로 사용합니다. 사업자등록·통신판매업 신고·PG 계약이 먼저 필요합니다.
- **뉴스레터 발송**: 지금은 구독 이메일만 모읍니다. 발송 서비스(스티비 등)를 정하면 연결합니다.
- **문의 알림 메일**: 이메일 발송 서비스(Resend 등)를 연결하면 새 문의를 메일로 받을 수 있습니다.

## 폴더 구조

```
src/
  app/(frontend)/     사이트 화면 (페이지별 폴더, styles.css)
  app/(payload)/      관리자 화면 (자동 생성, 수정 불필요)
  collections/        관리자 데이터 구조 (아티클, 아티스트, 장르, 이미지, 문의)
  globals/            사이트 설정, About 페이지
  components/         헤더, 풋터, 카드, 폼 등 공통 부품
  lib/                데이터 불러오기, 날짜·라벨 처리
  migrations/         데이터베이스 변경 기록
  seed.ts             샘플 데이터
```
